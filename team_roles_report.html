2. The 8-Step Image Preprocessing Pipeline

File: src/utils/imageProcessing.js (8,125 bytes) — Runs before any image reaches the AI.

StepNameTechnical AlgorithmThreshold
1 Blur Detection Laplacian Variance: lap = gray[above]+gray[left]+gray[right]+gray[below] - 4×gray[center] → variance of all lap values lapVariance < 75 → Blurry
2 Brightness Check Average pixel luma: 0.299×R + 0.587×G + 0.114×B luma < 45 → Too Dark; luma > 215 → Too Bright
3 Contrast Analysis Standard deviation of all pixel brightness values across entire image contrast < 22 → Low Contrast
4 Hair & Shadow Detection darkRatio = dark pixels / total pixels; combined with lapVariance heuristic darkRatio > 0.18 + lapVar > 120 → Hair; darkRatio > 0.22 + contrast > 75 → Shadow
5 Image Resize Proportional scaling — larger dimension capped at 1024px Max 1024px; Quality 0.88 JPEG
6 Brightness/Contrast Adjust ctx.filter = `brightness(${100+adj}%) contrast(${100+adj}%)` Manual slider control by user before submission
7 Saliency Heatmap Red-dominance: intensity = min(255, (R-(G+B)/2) × 2.2) → Jet palette mapping (Blue→Green→Yellow→Red) Composited at 55% opacity over original image
8 Base64 Conversion canvas.toDataURL('image/jpeg', quality) Sent as JSON to POST /api/analyze-skin
📊 Quality Score Formula (0–100 points)
  • Start with 100 points
  • Blurry image: -35 pts | Too dark: -20 pts | Too bright: -20 pts
  • Low contrast: -15 pts | Hair obstruction: -15 pts | Shadows: -15 pts | Poor framing: -10 pts
  • Bonus for very sharp image (lapVariance > 220): +10 pts

❓ Viva Questions & Expert Answers

Prepare these 6 answers — examiners commonly ask these questions for AI medical projects.

What is a Clinical Decision Support System (CDSS)?
A CDSS is an AI tool that helps doctors make better clinical decisions by analyzing patient data and providing evidence-based recommendations. Our system is NOT a replacement for doctors — it is a support tool that provides triage, differential diagnoses, and medication safety information to assist clinical judgment.
Why did you use Claude AND Gemini? Why not just one model?
Single-model dependency is a reliability risk. If Claude's API is down or rate-limited, Gemini automatically takes over. If both APIs fail, our local fallback classifier — which runs entirely on the server using pixel-level analysis without any external API — ensures the system never crashes. This 3-tier fallback architecture makes the system production-grade reliable.
What is Tinea Incognito and why did you implement detection for it?
Tinea Incognito is a dangerous condition caused by applying steroid creams on a fungal skin infection. Steroids suppress the immune response — redness appears to improve while the fungal infection spreads aggressively underneath the skin. It is one of the most common medication errors in dermatology. Our Drug Safety Engine automatically detects this scenario when a patient's history mentions steroids alongside a fungal diagnosis and raises a CRITICAL red-flag warning.
What is the Fitzpatrick Scale and why is it important in your project?
The Fitzpatrick Scale is a dermatological classification system that categorizes human skin color into 6 types based on melanin content and UV response — from Type I (very pale) to Type VI (very dark). Our system uses image luminance to auto-detect which Fitzpatrick type the patient is, so the AI can calibrate its analysis accordingly. This reduces racial bias in diagnosis, which is critical for a medical AI system to be fair and accurate across all populations.
What is ABCDE analysis in dermatology?
ABCDE is a standard dermatology screening rule for early melanoma detection: A = Asymmetry of the lesion, B = Border irregularity, C = Color variation within the lesion, D = Diameter greater than 6mm is a concern, E = Evolution or change over time. Our system computes A via quadrant pixel asymmetry scoring, B and C from pixel analysis, and E from patient-reported duration. If the mole scores high on these criteria, the system flags it as a priority dermoscopy case.
What are ICD-10 and SNOMED-CT codes? Why did you include them?
ICD-10 (International Classification of Diseases, 10th Revision) is the global standard medical coding system used by hospitals, insurance systems, and health records worldwide. SNOMED-CT is a comprehensive clinical terminology system. By mapping every AI diagnosis to its ICD-10 and SNOMED-CT code — for example, L40.0 for Psoriasis Vulgaris — our system's output can be directly integrated with hospital Electronic Medical Record (EMR) systems, making it clinically interoperable and professionally credible.
